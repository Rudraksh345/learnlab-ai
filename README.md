# MathMaster AI

Build ThinkMate AI, a modern mobile-responsive AI study app for Mathematics.

Student uploads one page of notes (image/PDF) → AI analyzes it and generates one concise learning dashboard with:

📝 Simple, concise notes

📌 Key concepts & definitions

📐 All formulas with variable meanings

💡 2–3 solved examples

🧮 Interactive simulation/visualizer when relevant

🧠 5-question MCQ quiz with instant feedback + score

🎯 Exam-focused important points

🤖 Dedicated AI Math Tutor using only the uploaded page and generated content, with “Explain simply”, “Solve an example”, “Give me a hint”, and “Quiz me” and that ai math tutor will also be able to  also explain in hinglish language

Use one structured AI generation workflow to minimize API calls and Lovable credits. Keep the UI clean, premium and student-friendly with cards, tabs, subtle animations and a blue/purple academic theme.

Dashboard: Notes | Concepts | Formulas | Examples | Simulation | Quiz | AI Tutor

Include Upload Another Page. Keep the MVP simple with no unnecessary features or complex backend.
